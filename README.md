# МНЕНИЯ — Fluid Ink Hero Landing

Интерактивный минималистичный лендинг со сборкой тонкого гротескного вордмарка **«МНЕНИЯ»** из органических чернильных капель на чистом белом фоне и флюидным курсором-метаболом (WebGL + GSAP).

## 🚀 Live Demo
- **GitHub Pages:** [https://trquestr.github.io/opinions/](https://trquestr.github.io/opinions/)
- **Лаборатория параметров курсора:** [https://trquestr.github.io/opinions/playground.html](https://trquestr.github.io/opinions/playground.html)

## ✨ Особенности
- **Сборка букв из жидких чернил:** ~71 органическая точка рождается в свободном пространстве холста, плавно парит и по касательным прямым траекториям вливается в контуры букв слова «МНЕНИЯ».
- **Динамическое поверхностное натяжение:** эффект капиллярного растекания и слияния капель с помощью гладкого полиномиального минимума (`smin` SDF) в кастомном GLSL-шейдере.
- **Интерактивный курсор:** скрытое поле чернильных точек, проявляющееся под курсором с органическим метаболл-слиянием (`goo`), физической инерцией и эффектом взрывной волны при клике.
- **Адаптивность:** идеальное центрирование и масштабирование под любые разрешения экранов и мобильные устройства.
- **Производительность:** 60+ FPS на WebGL.

## 🛠 Технологии
- WebGL 1.0 (GLSL Shaders)
- GSAP 3 (Timeline choreography)
- Vanilla JavaScript (ES6+)
- CSS3 / HTML5
